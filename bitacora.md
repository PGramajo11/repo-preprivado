## JS BITACORA

- Usaria const: para colocar una variable que no deberia ser reasignada con valores fijos ejemplo: const TASA_IVA = 0.16;
- Usaria let: para variable que estaran cambiando de valor conforme pase el tiempo de ejecución. Ejemplo: let puntos = 0;

## DIFERENCIA VS NPM VS CODE

- Node es una herramienta que nos permite ejecutar codigo JS fuera del navegador
- Npm es una herramienta que permite instalar, administrar y compartir bibliotecas de JS
- Es in programa que permite escribir, modificar y organizar archivos de programación como html, css  o js.

## PORQUE NODE_MODULES NO SE SUBE A GIT
- Primera causa es que ocupa mucho espacio, otro que no es necesario compartirlo por que otra persona lo puede instalar y evita cargar archivos innesaarios.
